# Independent concept site

- This is a separate GitHub Pages design preview. Never deploy to the original Cloudflare Worker or change production DNS.
- Do not use emoji or arrows, including arrow icons, in the website interface or content.
- Do not show the LINE ID or an ID-copy control. Preserve the approved contact destination URL.
- Reuse only already-public optimized photos. No original photographs, EXIF/GPS metadata, account configuration, credentials, or private research belong in public output.
- Do not invent business hours, metrics, prices, reviews, guarantees, certifications or live tracking.
- Use `npm run build`, `npm run check`, and `npm test`. The build fingerprints CSS and JavaScript.
- All pages must work under `/zonex-uiux-v2/`, be noindex, and keep canonical links to the existing official pages.
